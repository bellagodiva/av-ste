Noise Adaptive Streaming Audio-Visual Speech Token Enhancement
for Robust Full-Duplex Spoken Dialogue Models


📄 Paper 💻 Code 🤗 Models

Full-duplex spoken dialogue systems enable simultaneous listening and speaking, but their audio-only perception often fails under background noise and overlapping speech, leading to incoherent responses. Visual cues, such as lip movements, provide complementary information under audio corruption, yet existing audio-visual dialogue systems typically require large paired audiovisual datasets and costly end-to-end training. We propose AV-STE, a lightweight, streaming audio-visual front-end that recovers clean semantic tokens from noisy speech by fusing audio features with lip-ROI video — and plugs into any semantic tokens or hybrid tokens-based dialogue LM without re-training it.

  • Streaming AV Encoder — AV-HuBERT Large with causal convolutions and a bounded-lookahead mask (L = 4 frames, 160 ms), enabling real-time deployment with minimal latency.
  • Noise-Adaptive Fusion — soft token cross-attention attends to the speech tokenizer's full probability distribution, modulated by an entropy-based gate λt that automatically shifts toward visual information when audio is most corrupted.
  • Plug-and-play — enhanced semantic tokens replace the noisy stream directly; the speech LLM is kept fully frozen, requiring no additional fine-tuning.
  • +60% GPT coherence when plugged into Moshi at −10 dB SNR under both speech and ambient noise; WER reduced from 83.8%→62.9% (ambient noise) and 74.9%→58.2% (speech noise).

System Overview

AV-STE consists of two modules. The Streaming AV Encoder adapts AV-HuBERT Large with causal convolutions and a bounded-lookahead mask (L = 4, i.e., 160 ms of future audio context) to produce joint audio-visual representations in a streaming-compatible manner. The Noise-Adaptive Fusion module then applies soft token cross-attention — attending to the speech tokenizer's full soft distribution — gated by an entropy-based modulation signal λt = σ(w·Hnorm + MLP([et ‖ hav,t])). When audio is heavily corrupted (high entropy), the gate steers the model toward visual cues; as audio quality improves the balance shifts back. Enhanced semantic tokens replaced the noisy stream with no changes to the downstream speech LLM and acoustic tokens.

Table A — Semantic Token Recovery & Speech Intelligibility

  • Moshi's listening stream uses Mimi's first codebook (cb0) at 12.5 Hz as semantic speech tokens. Under noise, these tokens collapse — recovering them is the core challenge AV-STE solves.
  • Token accuracy: fraction of AV-STE's predicted cb0 tokens matching the clean reference. WER: Whisper-large-v3 transcription error rate on audio decoded from the token stream — a proxy for downstream speech intelligibility.

Table B — Full-Duplex Dialogue Coherence (Moshi)

  • The recovered token stream is fed directly into Moshi (kyutai/moshiko-pytorch-bf16, kept fully frozen) using the streaming inference protocol: 3 s silence pre-pad, Mimi-encode the full waveform, swap cb0 for AV-STE tokens, run the LM, trim output. No re-training of Moshi is needed.
  • This is the key downstream test: a coherent, on-topic spoken response indicates the LM received a meaningful semantic token stream; incoherent or off-topic responses reveal that the noisy baseline tokens were too corrupted for the LM to interpret. AV-STE restores dialogue coherence at −10 dB SNR, achieving a +60% improvement in GPT-4 coherence score under both noise conditions.
